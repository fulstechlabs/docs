## Choose your question

| Your question | Report to use |
| --- | --- |
| Where does work wait? | **Time in status** |
| How long does delivery take? | **Cycle time** or **Lead time** |
| Which current issues have been waiting longest? | **Current visit age** |
| Who owned the issue over time? | **Assignee time** |
| How often did work enter or move between statuses? | **Status count** or **Transition count** |
| When did an issue enter a status? | **First status entrance** or **Latest status entrance** |

**Assignee time is elapsed ownership, not hours worked.** The app focuses on workflow time; timesheets and billing are outside its scope.
