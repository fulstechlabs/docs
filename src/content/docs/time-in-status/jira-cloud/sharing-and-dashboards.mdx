Save a useful report once, then share its configuration or display it in a Jira dashboard. Results remain permission-aware and are recalculated for the current viewer.

## Choose how to reuse a report

<Tabs>
<TabItem label="Share">

1. Configure a report and choose **Save as new**.
2. Select the saved report under **Private saved reports**.
3. Choose **Share configuration**.
4. Copy the **Share link** and send it to your teammates.

**Result:** teammates open the same settings and run them using their own Jira access. Review saved JQL before sharing because it is part of the configuration.

Choose **Stop sharing** to disable existing links. A recipient can save a separate private copy.

</TabItem>
<TabItem label="Dashboard">

1. On a Jira dashboard, choose **Add gadget**.
2. Find and add **Workflow Time report**.
3. Choose a saved report and select **Save gadget**.

**Result:** the gadget shows up to 25 issues using each viewer's Jira access. Open the full report for larger selections.

Share the saved configuration if other dashboard viewers need to use it. A private configuration remains available only to its owner.

</TabItem>
</Tabs>

Sharing copies settings, not report results or export files. If a viewer cannot access an issue in Jira, the shared report or gadget does not grant access to it.

Need a file instead? Continue to [Exports](../exports/).
