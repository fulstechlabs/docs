Use the report that answers your question, then confirm the scope, calendar and measurement window before comparing values.

## Choose a metric

| To find… | Choose… |
| --- | --- |
| Time spent in each status | **Time in status** |
| Workflow loops and rework | **Status count** or **Transition count** |
| When a status was entered | **First status entrance** or **Latest status entrance** |
| Duration through selected workflow states | **Cycle time** |
| Created-to-completion or selected-status lead time | **Lead time** |
| Current waiting time in the present status | **Current visit age** |
| Elapsed ownership by assignee | **Assignee time** |

**Time in status** totals all observed visits to a selected status, including the current visit up to the calculation cutoff.

## Configure statuses and groups

Open **Statuses and optional groups → Load statuses from scope** when a metric needs workflow states.

- Leave the status selection empty to include all observed statuses where the metric allows it.
- Create report-scoped status groups such as Waiting or Active work.
- For **Cycle time**, select the statuses and/or groups that define your cycle.
- For **Lead time**, choose the lead-time definition and completion/status selections that match your workflow.
- Do not add overlapping group totals together or add a group to its member statuses.

## Compare grouped results

Open **Group results** and choose one dimension:

- Project
- Current assignee
- Issue type
- Component

Choose **Total** or **Mean per contributing issue**.

Grouping uses current Jira fields rather than reconstructing historical team membership. Issues with multiple components can appear in multiple component groups.

## Inspect the visits behind a value

Choose **View history** on an issue row.

<GuideFigure image={historyImage} alt="Status visit with entrance date, exit date and measured duration" caption="Use issue history to inspect the visits behind a report value." />

Status count includes the initial status at creation. Transition count is directional. Entrance-date metrics refer to the first or latest observed entrance in the measurement window.

**Assignee time measures elapsed ownership, not logged effort or individual productivity.**
