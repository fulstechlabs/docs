---
title: "Exports"
description: "Export the current report page or all collected report pages as CSV."
---

Time in Status exports CSV from a fresh calculation so you can keep or analyze a copy of the report.

## Export the current page

1. Run the report and review its scope and completeness.
2. Choose **Export this page as CSV**.
3. When preparation finishes, choose **Download CSV** and save the file.

The export recalculates data, so the cutoff and open durations can differ from the result currently on screen.

## Export all collected pages

1. Set **Report scope** to **All search pages**.
2. Run the report and confirm the collected population and completeness.
3. Choose **Export all pages as CSV**.
4. Download the prepared CSV.

All-pages export traverses the selected Jira search again. Jira search membership can change during traversal, so the file is not an atomic database snapshot.

## Check limits and completeness

Interactive all-pages reports are bounded by application limits, including issue/page/result-size limits. If a large selection cannot complete, narrow the project or JQL and try again.

Missing values are not zero. Resolve issue errors before using partial totals.

Downloaded CSV files are stored wherever you save them and remain under your control. For repeated failures, see [Support](../support/).
