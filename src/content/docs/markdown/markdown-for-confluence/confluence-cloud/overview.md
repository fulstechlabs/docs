Write Markdown and LaTeX in a Confluence macro, review the formatted result,
and keep the source available for later editing or download.

**Start here:** [Create your first Markdown macro](../usage/). Write source,
select **Save and close**, then publish or update the Confluence page.

:::note[Which editor do you have?]
These guides describe the **Forge edition** with the editor shown below.
If your macro still opens the older editor with a check icon, use the
[Connect editor guide](../connect-editor/). Installation and update availability
are controlled through Atlassian Marketplace and your Confluence administrator.
:::

## Where it fits

Use the macro for engineering notes with formulas, Markdown tables alongside
explanations, or source that you want to keep as Markdown instead of converting
it into native Confluence blocks. The macro has its own source inside the page;
normal Confluence permissions and the page's publish/update workflow still apply.

A Confluence administrator installs the app from
[Atlassian Marketplace](https://marketplace.atlassian.com/apps/1226896/markdown-macro-with-latex-for-confluence-cloud).
An active evaluation or subscription is required. Page authors also need
permission to edit and publish or update the destination page.
