**Markdown Rich Text Editor for Jira** (also known as **Markin**) lets you write Markdown source, preview it, and save it back to Jira. Use it for requirements, acceptance criteria, technical notes, and runbooks.

This guide covers **Forge Cloud 3.6.0**. [Data Center and Server have separate instructions](../../jira-data-center-and-jira-server/overview/).

## Where the app works

| Surface | What you do |
| --- | --- |
| Project settings → Apps → Markdown Fields | Choose existing fields and issue types; configure Gherkin highlighting |
| Issue → Rich Text Custom Fields | Read, edit, preview, and save content |
| Jira's native field display | Read a text representation of app-owned fields |

The app does not replace all Jira editors. Full math, diagrams, and formatted Markdown appear in the app panel, not every search, email, or export surface.

## What you can write

- Headings, lists, tables, links, and highlighted code blocks.
- LaTeX math for technical explanations.
- Mermaid, Graphviz, and sequence diagrams.
- Gherkin acceptance criteria.
- User references and links to existing issue attachments.

Image references display as **links**, not automatically loaded images. The Forge release does not include the legacy AI Copilot.
