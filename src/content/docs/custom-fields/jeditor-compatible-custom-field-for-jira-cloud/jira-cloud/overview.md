This Jira Cloud app provides **JEditor-compatible Custom Fields** to ease the migration from Jira Data Center or Server to Jira Cloud for users of the [JEditor - Rich Text Editor for Jira plugin](https://marketplace.atlassian.com/apps/1210768/jeditor-rich-text-editor-for-jira?tab=overview).

## Choose your app version

The existing installation and migration guides below describe the **legacy Connect app**.
The Forge successor, **JEditor Release 1.1**, has been deployed to Forge but is
**not yet approved or available as a Marketplace successor**. Deployment does
not automatically update your Jira installation.

For an explicitly enabled Forge evaluation, see [Use the Forge successor](../forge-successor/).
Review its [security and data handling](../security-and-data/) and
[privacy policy](../privacy-policy/) before planning adoption.
These pages do not instruct existing customers to uninstall or replace their app.

> **info**
>
We are not the developer of the JEditor plugin. We only develop the Jira Cloud app that provides compatible custom fields so that users of the original plugin can migrate their data from Jira Data Center or Server to Jira Cloud successfully.

You can install the app by following the instructions at <https://marketplace.atlassian.com/apps/1231698/jeditor-compatible-custom-fields-for-jira>
