## Before opening a request

For a missing panel or field, confirm that the project administrator:

- added the field in **Project settings** > **Apps** > **JEditor Fields**;
- selected the current issue type;
- selected **Save** and saw the **Saved** status; and
- used a supported **Description**, **Text Field (multi-line)**, or **JEditor Rich Text** field.

For an editing problem, try the same action on a non-production test issue, then reload the issue to confirm whether the value was saved. Use the **JEditor Fields** panel rather than Jira's native editor for configured rich-text content.

## What to include

Send the following information when it is safe to share:

- Jira site URL, project key, and issue key;
- app version and whether the project settings entry is named **JEditor Fields** or **JEditor-compatible Fields**;
- field name and field type;
- issue type;
- the steps that failed and the result you expected;
- the time of the failure, including your time zone; and
- a screenshot with confidential issue content removed or obscured.

Do not send passwords, API tokens, session cookies, or an unredacted browser archive. Remove confidential issue content unless your organization has approved sharing it through the support channel.
