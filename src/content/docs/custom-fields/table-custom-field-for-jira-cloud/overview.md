> **This app only works with Company-managed (formerly Classic) projects.**

This app for Jira Cloud provides a native Table Custom Field Type.

Users can:

* Configure columns of the table.
* Edit cell content using Markdown.
* Add, remove, and reorder rows.

Thanks to the new capability of the Jira Cloud platform, the Custom Field Type offers native support for existing Jira Cloud RESTful API, changelogs, email notifications, and any other built-in functions of Jira Cloud.

You can install the app by following the instructions at Atlassian Marketplace <https://marketplace.atlassian.com/apps/1229578/table-custom-field-with-markdown-for-jira-cloud>.
