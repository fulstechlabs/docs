## Is Better Pages a replacement for the Confluence editor?

No. It adds page-building components and reviewed workflows around normal
Confluence content. Rich-body macros continue to use the Confluence editor.

## Which macro should I use first?

Start from the reader's task in the [Macro Catalog](../macros/). Use native
headings and links when they are enough; use a Better Pages component when its
layout or interaction improves understanding.

## Can I use my organization's colors and assets?

Yes. Administrators can publish global colors and Brand Kits. Authors can then
select supported colors, images, and icons without copying values or URLs.

## Does Smart Designer require AI?

No. Formatting, component creation, native block editing, preview, draft, and
publish workflows work without AI. AI rewrite is a separate administrator
opt-in and author-triggered action.

## Can Better Pages change pages I cannot edit?

No. Confluence permissions apply to searches, previews, and writes. Smart
Designer, Space Manager, templates, and Numbered Headings run as the signed-in
account.

## Does HTML JavaScript have access to Confluence or the network?

No. When an administrator enables it, JavaScript runs in an opaque-origin
sandbox that blocks network access, forms, downloads, pop-ups, and host
navigation.

## Does Better Pages collect form responses?

No. The retained local form compatibility feature validates required fields in
the browser and has no submit destination. Better Pages does not receive or
store entered values.

## Can Better Pages automatically migrate Mosaic Data Center data?

No. The current Cloud app does not read another vendor's private app data or
automatically convert Data Center macros. A future assisted migration would
require an explicit, separately delivered migration path and customer action.

## What happens when a Brand Kit is unpublished?

It disappears from new author selections. Existing macros keep their saved
snapshot so published pages do not unexpectedly change.

## Where can I get help?

Use the [troubleshooting guide](../troubleshooting-and-support/) first. If the
problem remains, contact the
[Fulstech support portal](https://fulstech.atlassian.net/servicedesk/customer/portals)
with a minimal reproduction and redacted screenshot.
