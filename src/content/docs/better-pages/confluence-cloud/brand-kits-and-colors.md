---
title: "Brand Kits and Colors"
description: "Publish reusable colors, images, and icons for Better Pages authors."
---

Site administrators use **Brand Kits** and **Colors** to give authors a trusted,
reusable visual library without requiring them to copy asset URLs or color
values between pages.

## Manage shared colors

Create a named color with a valid hex value, edit it when needed, and publish it
for authors. Published colors appear in supported macro color pickers alongside
built-in, recent, local-space, and custom choices.

## Build a Brand Kit

1. Create a kit with a clear name.
2. Add colors and upload images or icons.
3. Review asset names and previews.
4. Publish the kit and optionally make it the default.
5. Open a macro configuration and confirm the kit appears in its supported
   color, image, or icon picker.

Uploads are verified before a kit can be saved. A batch can contain one to eight
assets, each no larger than 5 MB.

## Publication behavior

Draft kits stay in administration. Published kits are available to authors.
Unpublishing a kit removes it from new selections, but existing macros keep the
colors and verified asset references that were snapshotted when they were saved.
This prevents an unrelated kit edit from unexpectedly redesigning published
pages.

## Good practice

- Use human names such as `Primary action` rather than only hex values.
- Publish a small, intentional palette with accessible contrast pairs.
- Remove duplicate and obsolete assets before encouraging adoption.
- Test the default kit in Background, Alert, Button, Cards, Tabs, and Banner.
