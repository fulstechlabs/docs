---
title: "Smart Designer"
description: "Format page content, add Better Pages components, or edit supported native blocks from one reviewed canvas."
---

**Smart Designer** helps page editors make several coordinated changes while
preserving a review step. Open it from a published page's Better Pages byline
action. The editor launcher can preview the current draft, but write actions are
available from the published page so Smart Designer cannot overwrite unsaved
editor work.

## Choose a workflow

| Workflow | What it does |
| --- | --- |
| Format existing content | Turns at least 10 selected words into a configured Better Pages design, while keeping or replacing the source blocks |
| Add a component | Appends any of the 19 Better Pages components without selecting text |
| Edit native page content | Adds, formats, reorders, duplicates, or removes supported headings, paragraphs, lists, quotes, code, panels, dividers, and simple tables |

Existing macros, complex tables, and media are protected rather than silently
rewritten.

## Review and apply a design

1. Choose a workflow and, when required, select source blocks.
2. Choose a component and configure it in the canvas.
3. Select an optional published Brand Kit.
4. Preview the result, then add it to the staged canvas.
5. Edit, reorder, or remove staged items.
6. Choose this page or one new child page as the output.
7. Select **Save draft** or **Publish**.

Smart Designer checks the source page version before writing. If the page
changed, reload the source and review the canvas again.

## Optional AI rewrite

When a site administrator enables **AI in macros**, an author can explicitly
send selected text and one of six tones to an Atlassian-hosted Forge LLM. The
non-AI workflow remains complete when this setting is off. Always review
generated wording before staging or publishing it.

## Good practice

- Update or close any open Confluence editor before applying changes.
- Use **Save draft** for substantial changes that need review.
- Preview every component interaction after publishing.
- Use the native editor only for supported simple blocks; edit protected content
  in Confluence itself.
