Better Pages provides 19 macros for layout, navigation, communication,
technical content, and structured data. Start with the reader's task, then
choose the smallest component that supports it.

## Layout and visual design

| Macro | Best for |
| --- | --- |
| Background | Giving a section color, artwork, spacing, and a clear visual boundary |
| [Advanced Cards](./advanced-cards/) | Visual directories, owner lists, resource hubs, and linked choices |
| Interactive Banner | Hero areas, announcements, campaigns, and rotating highlights |

## Navigation and actions

| Macro | Best for |
| --- | --- |
| [Tabs](./tabs/) | Dividing a long page into a small number of related sections |
| [Button](./button/) | One prominent next action or destination |
| Button Group | A related set of buttons arranged horizontally or vertically |
| Progress Bar | A sequence, status journey, or set of linked milestones |

## Messages and supporting detail

| Macro | Best for |
| --- | --- |
| [Alert](./alert/) | Inline messages and page-load notices that can be dismissed |
| Advanced Expand | Optional detail that opens in place |
| Pop-up Dialog | Focused supporting content opened from a button |
| Tooltip | A brief explanation attached to a compact trigger |

## Technical and research content

| Macro | Best for |
| --- | --- |
| LaTeX Builder | Text with one or more display or inline equations |
| LaTeX Inline | One compact equation inside a sentence |
| Footnote | A source note or explanation linked from the reading flow |
| Footnote Summary | Collecting Footnotes above it into a numbered list |
| BibTeX Reference | One structured academic or technical citation |
| BibTeX Summary | A searchable, sortable table of BibTeX references |
| HTML | Safe, local HTML content and interaction inside the macro |
| Table | Searchable, sortable, filterable Confluence table data |

## Choose a component, not a decoration

Use a component only when it improves a reader's task:

- Prefer headings on short pages; use Tabs when sections are substantial.
- Prefer a normal Confluence link inside a sentence; use a Button for a clear
  next action.
- Prefer a native Confluence panel for a simple static note; use Alert when you
  need Better Pages styling, images, or dismissal.
- Prefer a short link list; use Advanced Cards when descriptions, ownership,
  imagery, or visual grouping help readers choose.

The four linked guides above are the first documentation pilot. Guides for the
remaining macros will follow the same structure after the pilot is reviewed.
