Use **Better Pages LaTeX Inline** for one mathematical expression that belongs
in the surrounding sentence. Write the prose in Confluence and keep only the
equation in the macro.

## Add an inline equation

1. Insert **Better Pages LaTeX Inline** at the required point in the sentence.
2. Enter one expression, with or without `$...$` delimiters.
3. Use command suggestions and review the live preview.
4. Fix validation warnings, save, and publish.

For example, write `The relationship `, insert the macro with `E = mc^2`, then
continue with ` connects energy and mass.`

## Good practice

- Keep the expression compact. Use [LaTeX Builder](../latex-builder/) for a
  large or multi-line formula.
- Explain unfamiliar variables in the surrounding text.
- Read the complete published sentence to confirm spacing and punctuation.
