---
title: "Footnote Summary"
description: "Collect preceding Better Pages Footnotes into a linked numbered list."
---

Use **Better Pages Footnote Summary** at the end of a section or page to collect
the Footnotes that precede it.

## Add a summary

1. Add every [Footnote](../footnote/) beside its supporting text.
2. Insert **Better Pages Footnote Summary** after the last note to collect.
3. Enter an accessible heading such as `Notes` or `Sources`.
4. Publish the page and activate links in both directions.

The summary uses published page order. A second summary starts a new collection,
so it does not repeat notes already collected by the earlier summary.

## Good practice

- Use a heading that matches the purpose of the notes.
- Keep the summary near the content it supports.
- Publish before judging numbering; editor placeholders are not the final order.
- Do not use a summary without Footnotes above it.
