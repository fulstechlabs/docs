Start with [Troubleshooting](../troubleshooting/) for common formula, reference, equation-list, permission, and license problems.

If you still need help, submit a bug or feature request through the [Fulstech support portal](https://fulstech.atlassian.net/servicedesk/customer/portals).

## Include this information

- Product: LaTeX for Confluence Cloud.
- The exact macro name, such as **LaTeX Math — display** or **Advanced LaTeX — display**.
- Whether the problem occurs while editing, on a published page, in PDF/Word export, or in another viewing surface.
- Clear reproduction steps.
- Expected and actual results.
- The visible error message, if any.
- A sanitized screenshot that includes enough Confluence context to locate the problem.
- Whether the content originated in the Cloud Connect version or a Data Center/Server migration.

Do not send passwords, session cookies, API tokens, confidential formulas, raw browser archives, or unrelated customer data. Support may request additional diagnostics after reviewing the initial report.

The app does not include an external analytics or support-chat SDK. A support request is the normal way to share diagnostic context with Fulstech.
