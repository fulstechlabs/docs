This guide creates a display equation that readers can see on a Confluence page.

## Before you start

- LaTeX for Confluence must be installed with an active Marketplace license or trial.
- You need permission to edit and publish the target Confluence page.

## Add the formula

1. Open a Confluence page and select **Edit**.
2. Type `/LaTeX Math`.
3. Choose **LaTeX Math — display**.
4. Enter `E=mc^2` in **LaTeX source**, or type the same expression in **Visual editor**. The two surfaces stay synchronized.
5. Confirm that the rendered formula looks correct.
6. Select **Save** in the macro editor.
7. Select **Publish** or **Update** in Confluence.

You have succeeded when the page shows the equation on its own line without an editor frame.

## Choose a different placement

Use **LaTeX Math — inline** when a formula belongs within a sentence, for example: “Energy is described by `E=mc^2`.” Inline macros do not show alignment controls.
