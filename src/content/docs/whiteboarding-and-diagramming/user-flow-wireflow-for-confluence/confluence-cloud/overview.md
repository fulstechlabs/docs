**User Flow (Wireflow) for Confluence** helps you create beautiful user flow prototypes and you don't need to install or have previous experience in any complicated software.

You can install the app by following the instructions at [Atlassian Marketplace](https://marketplace.atlassian.com/apps/1227630/user-flow-wireflow-for-confluence).
