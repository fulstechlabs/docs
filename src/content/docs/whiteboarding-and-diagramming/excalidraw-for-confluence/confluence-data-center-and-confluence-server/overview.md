**Excalidraw for Confluence** adds visual and text-defined diagrams to
Confluence Data Center. Use it for informal whiteboards, UI wireframes, UML,
software architecture, and relationship graphs.

## Included macros

- **Excalidraw** for canvas-based drawings and wireframes.
- **Mermaid UML** for diagrams maintained as Mermaid source.
- **PlantUML** for UML and other PlantUML-supported diagrams.
- **Graphviz** for graphs maintained as DOT source.

The Data Center app is available from
[Atlassian Marketplace](https://marketplace.atlassian.com/apps/1226438/excalidraw-for-confluence?hosting=datacenter&tab=installation).
Use the Marketplace compatibility table to choose the release for your
Confluence version. Atlassian no longer offers new Server app sales; existing
Server customers should review Marketplace support and compatibility before an
upgrade.

Follow the [Data Center usage guide](../usage/) to create and edit diagrams. If
you use Confluence Cloud, start with the [Cloud overview](../../confluence-cloud/overview/).
