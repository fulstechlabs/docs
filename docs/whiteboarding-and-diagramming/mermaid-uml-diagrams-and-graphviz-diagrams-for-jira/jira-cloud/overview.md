# Overview

> **If you are using Jira Data Center or Jira Server, please see** [**this page**](../jira-data-center-and-jira-server/overview.md)**.**

This is the only add-on for rendering Mermaid UML diagrams inside Jira Cloud. Mermaid (<https://mermaid-js.github.io/mermaid/#/>) allows you to define UML diagrams in plain-text format just like Markdown. Support multiple types of charts and diagrams:

* Graphviz
* Flowchart
* Sequence diagram
* Class diagram
* State diagram
* User Journey
* Gantt chart
* Pie chart

You can install the app by following the instructions at [Atlassian Marketplace](https://marketplace.atlassian.com/apps/1223053/mermaid-uml-diagrams-for-jira-cloud?hosting=cloud\&tab=installation).
