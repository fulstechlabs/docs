# Overview

> **If you are using Jira Data Center or Jira Server, please see** [**this page**](../jira-data-center-and-jira-server/overview.md)**.**

This is the app for rendering LaTeX inside Jira Cloud.

You can install the app by following the instructions at [Atlassian Marketplace](https://marketplace.atlassian.com/apps/1223629/latex-beautiful-math-for-jira-cloud?hosting=cloud\&tab=installation).
