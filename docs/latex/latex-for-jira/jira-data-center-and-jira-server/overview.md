# Overview

> **If you are using Jira Cloud, please see** [**this page**](../jira-cloud/overview.md)**.**

LaTeX for Jira is the only app for rendering LaTeX inside Jira Data Center and Jira Server.

You can install the app by following the instruction at [Atlassian Marketplace](https://marketplace.atlassian.com/apps/1215859/latex-beautiful-math-for-jira-data-center-and-jira-server?hosting=datacenter\&tab=overview).
